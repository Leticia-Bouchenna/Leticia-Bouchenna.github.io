# Leticia Bouchenna — Portfolio

Professional portfolio of Leticia Bouchenna, Data Scientist working in Applied AI, multilingual data and decision intelligence.

Live site: [leticia-bouchenna.github.io](https://leticia-bouchenna.github.io/)

## Technologies

- React 18 and TypeScript
- Create React App
- SCSS
- Material UI, Font Awesome and React Icons
- GitHub Actions and GitHub Pages

## Run locally

Requirements: Node.js 20 and npm.

```bash
npm ci
npm start
```

The development server is available at `http://localhost:3000`.

Create a production build with:

```bash
npm run build
```

The static output is generated in `build/`.
