## Built With

React 18 · TypeScript · SCSS · GitHub Actions · GitHub Pages

## Run Locally

```bash
git clone https://github.com/Leticia-Bouchenna/Leticia-Bouchenna.github.io.git
cd Leticia-Bouchenna.github.io
npm ci
npm start
```

Production build:

```bash
npm run build
```

## Deployment

Pushes to `main` are automatically built and deployed through GitHub Actions and GitHub Pages.
